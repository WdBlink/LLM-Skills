# Photographer Style · 摄影师风格拆解

Version: 0.6.1

从哔哩哔哩、YouTube 摄影拆解视频或用户提供的样片，整理图文证据，生成风格介绍、关键参考图与双模式提示词，并按请求归档到 GitHub 私有仓库。

在视觉分析与提示词之间提炼创作决策：从跨作品证据归纳关注点、触发条件、选择动作及取舍，驱动参考选择与新主体的拍摄设计；用留出作品、新情境推演和反例检查其适用范围。照片中的结果、本人陈述与分析假设分别记录，文字推演不等于生成实测。具体规则保存在各风格的分析稿和提示词中，通用方法见 [风格转化流程](references/style-to-prompt.md)。此方法借鉴 [女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill) 的框架提炼与验证思路，无需安装或运行该技能。

## 安装

```bash
mkdir -p ~/.codex/skills/photographer-style
rsync -a skills/photographer-style/ ~/.codex/skills/photographer-style/
```

## 使用

```text
使用 $photographer-style，分析这位摄影师的样片，生成一份风格介绍 README，以及主动模式、微调模式各自的 README.md，并附上关键参考图。
```

也可提供摄影师姓名、视频链接、本地视频或现成文字稿，从对应阶段继续。默认保存于当前工作区的 `generated/photographer-style/`；具体命令见 [媒体流程](references/media-workflow.md)。

每个风格在设计提示词时先分析适合的原片：人物数量与景别、面部可辨性、场景、光照和人物呈现诉求，并把适用条件与不匹配处理写入提示词正文。参考图按这些条件选择，没有相容参考可只用原片。

主动模式拆解该风格中人物为何好看，再改善美颜、表情动作、发型与构图；默认保留场景地点，允许在同一现场重绘细节和调整光线，明确要求后才换地点。微调模式只改光影、色调和局部遮瑕。每个风格有独立介绍 `README.md`；两份提示词分别位于 `prompt-assets/主动模式/README.md` 与 `prompt-assets/微调模式/README.md`，共用 `prompt-assets/reference/` 中的参考图。移动或分享时保留整个资产目录。

视频流程使用 yt-dlp、FFmpeg 和本地 Whisper 后端，依赖与权重不随技能安装。由 Agent 调用现有工具、查看画面并组织产物，无额外常驻服务。仅有图片时无需安装下载和转写工具。实际下载可用性及转写质量须用目标视频验证。

## GitHub 归档

```text
使用 $photographer-style，把这套已完成的本地提示词和参考图上传到我指定的私有仓库 <owner>/<repo>，本地目录为 <archive-dir>，更新风格介绍并核验远端文件。
```

归档目标来自当前用户的指定或已有明确配置；先核对实际账户、远端和本地目录，不内置个人仓库路径。已有资产直接整理并上传；正常风格分析不自动触发上传。归档包括私有性核验、原资产保留、统一目录、链接检查、Git 提交推送与远端确认，详见 [GitHub 归档流程](references/github-archive.md)。

本版本为通用技能；具体摄影师案例与图像编辑效果需要真实素材验证。本仓库公开可见；该技能保留权利（Proprietary），公开展示不授予开源再分发或商用许可。

当前用户明确配置并选择棚拍创作模式时，按该配置确定原片的身份用途和服装、布景、拍摄呈现的可调整范围；摄影师姓名本身不代表授权。执行生成前先实际查看完整候选图库，再选择主参考与必要辅助；全组上传时仍须选主次。图片读取与上传由执行 Agent 完成，不能仅把目录路径写进提示词。
