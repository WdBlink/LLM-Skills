# 把风格逻辑转成照片编辑动作

## 建立范围与证据

先确认用户想接近的摄影师、时期/系列和所给样片。用户偏爱某一组作品时以这组为范围，不用摄影师其他作品覆盖用户选择。不凭图像猜作者；用户提供的归属注明“用户标注”，需要研究身份时另查可靠来源。

逐条回应用户已有理解：哪些得到画面支持，哪些仅在部分作品成立，哪些需要修正，哪些证据不足。补充分析要指出对应图片或视频时间。参考图本身比转述更直接，但一组样片也不能证明“所有作品都如此”。多人转载同一张作品不算多个独立例子。

分析以下与材料相关的维度，不为了填表推断不存在的信息：

| 维度 | 要辨认的规律 | 对编辑的意义 |
|---|---|---|
| 题材与观看方式 | 关注什么、与主体的距离、日常性或戏剧性 | 指导筛选适用原片；避免靠换主体来伪造风格 |
| 构图与空间 | 主体占比、留白、边缘关系、遮挡、层次、透视 | 区分能靠视觉权重调整的效果与需要重拍的几何 |
| 光线 | 方向、软硬、光比、顺逆光、光源颜色与阴影形态 | 微调保留受光结构；主动模式可协调重布光及其阴影、反射 |
| 影调 | 黑位、白位、中间调、局部对比、高光过渡、暗部细节 | 明确哪些区域压暗/提亮，避免把“柔和”写成全图灰蒙 |
| 色彩关系 | 主次色、色相偏移、明度/饱和度分配、冷暖分区、肤色 | 写颜色之间的关系和局部目标，不只写“低饱和/胶片感” |
| 质感与清晰度 | 细节锐度、微对比、颗粒、光晕、景深或运动模糊 | 区分可模拟表面质感与会破坏主体信息的处理 |
| 情绪与叙事 | 什么视觉安排造成疏离、亲密、安静或紧张 | 用形式解释情绪，不能只堆抽象形容词 |

每条核心判断写成：**规律 → 图像/时间证据 → 视觉作用 → 适用条件 → 可执行动作**。示例仅说明写法，不是任何摄影师的预设风格：

> 两张样片中背景绿色比主体肤色更低饱和，主体中间调更明亮，注意力因此集中在脸部。若原片有人物及绿植，可降低背景绿色的饱和度与亮度，保护肤色与面部层次；没有这类背景时不添加绿植。

证据明确标成“用户观点 / 解说观点 / 直接画面观察 / 推断”。核心特征优先选择跨不同作品重复出现的关系；单个例子写成局部观察。矛盾先检查系列差异、仿拍对照、截图质量，不混合成自相矛盾的调色要求。没有 EXIF 或作者资料时，不宣称镜头焦距、胶片型号、曝光参数为事实。

先还原来源自身的分析框架、核心主张与因果关系，再用上述维度补漏。回答“摄影师关注什么、用什么画面组织与光色关系表达、为什么产生这种观感”。不要将原本具体的影调结构、构图秩序和分区色彩，压缩成“自然、明亮、低饱和”等通用形容词。

对来源的重要判断逐项记录其在两版提示词中的落点：主动模式可以怎样实现，微调模式能迁移哪部分，未采用的部分为何不适用。反例限制普遍性，不自动否定当前子集的特征；例如某系列常见的画幅仍可成为主动模式的明确选择，不因其他系列存在不同画幅就完全删去构图逻辑。

## 从视觉规律提炼创作决策

在图文分析后、写提示词前，将视觉特征归纳为能用于新主体的选择规则。借鉴女娲的“思维框架—条件式决策—验证”方法，只吸收与摄影任务相关的部分；不要求运行人物生平、口吻模拟、固定数量模型或固定多 Agent 流程。

从材料中提取：观看时优先关注什么；根据哪些条件选择拍摄方法；哪些视觉关系的组合形成辨识度；真实与设计、亲近与距离等目标如何取舍；哪些表面符号容易被误当成风格。只保留有证据的张力，不为凑数制造矛盾。

### 证据与筛选

成片支持“出现了什么视觉结果”；本人访谈、拍摄记录、联系印样或幕后材料可补充“为什么选择、如何实现”。教学解说与第三方仿拍分别标注，不能作为本人意图或实际灯位的直接证明。先复用现有素材，只有具体规则存在证据缺口且任务范围允许时再定向补充资料。

按三个问题筛选候选规则：

- **跨作品复现**：不同人物、场景或拍摄任务中是否出现相同的关系？同一作品的截图、裁剪和转载不算独立证据。单例保留为局部方法，多次出现也不自动证明本人信念。
- **生成力**：换一个主体或约束后，能否给出有理由的选择及调整？若只能复制参考的服装、颜色或姿态，尚未提炼出可迁移规则。
- **组合辨识度**：相较通用摄影建议，哪些方法的组合、优先级或触发条件有区别？不要求每个技巧独有；“主体突出、颜色协调”本身不足以构成专属规则。

证据不足时缩小适用范围或标为待验证假设，不凑固定条数、来源比例或重复次数。跨系列差异先按时期、题材和委托条件分开；无法解释的反例保留，不编造统一动机。此处形成的是可修订的创作规则，不声称还原摄影师全部思维或预测其本人选择。

### 记录并转成执行顺序

在现有 `style-analysis.md` 中为每条核心规则记录：

> 规则与适用系列 → 来源、图像/时间及证据等级 → 关注的问题 → 触发条件 → 选择动作及视觉作用 → 冲突时的取舍 → 反例与失效条件 → 主动/微调正文落点 → 验证状态

根据这些规则组织本次设计：读取主体与用户约束，确定表达目标，比较能解决该摄影问题的参考，联合决定相关的景别、机位、动作、空间和光色，再检查整套选择是否相容。保留真实的先后依赖；这是执行端的工作顺序，除非有记录，不宣称是作者实际拍摄顺序。微调模式只运行不改变内容与几何的选择，不能因“摄影师会这样拍”而扩大用户授权。

例如，若作品证据支持“手与脸共同组织注意力”，可推导：手势能强化当前表达且允许重构时，比较含手半身与头肩方案，联合安排手脸距离、机位和受光；手势无帮助时采用近景。微调输入未露手时只迁移相容的注意力分配，不新增手。该例说明条件式写法，不是所有摄影师的默认要求。

## 先设计原片适用范围

在写编辑配方前，从该作品子集的实际图像推导输入条件：什么样的原片具备实现这些视觉关系的基础。依次检查人物数量、近景或全身等观看尺度及面部可辨性；室内外和地点在照片中的叙事作用；光的方向、软硬、光比与现有亮暗面积；可利用的服装、环境色块和空间层次；用户想要的自然、时尚或正式等人物呈现。条件必须有对应的样图或已知证据，适配推断与直接观察分开写。

每个风格形成三类结论：最适合什么素材；哪些素材只可迁移部分关系；哪些素材不宜强套。把简明而具体的结论写进风格介绍和两版可复制提示词正文，附不匹配时的处理。主动版可用同一地点内的姿态、取景与光线调整扩大适用范围；微调版不能靠这些结构变化获得适配。不能所有风格都只写“适合人像、照片要清晰”，也不能等失败后才补适用条件。

保留现场的任务中，有用户原片时先选适合其基础条件的风格，再选参考图。匹配以场景类型、人物关系、受光与景别为主，不能仅因背景同色或脸部偏暗就套用。单人参考不应支配合影关系；室内参考不能把户外原片搬进房间。参考不相容时不上传，改用该风格完整文字中相容的关系；原片本身不适合时换合适风格或明确减弱处理，不通过换地点来假造适配。

## 为当前人物选参考：执行端与生成端分工

用户明确采用棚拍重新创作的模式时，原片只提供身份与可见外貌，原地点、衣服、光线和颜色不能成为筛除参考的硬条件。具体范围以当前用户的明确配置和授权为准，不从摄影师姓名推定。根据人物可见的面部、头肩、发质、配饰、神态及希望表达的视觉气质来设计拍摄，不从外貌推断真实职业、性格或经历。选参考关注摄影关系怎样呈现本人，不以模特长得像或属于同一人群作为理由。

生成前由执行 Agent 实际查看完整候选图集，逐图判断主用、辅助或不采用的理由，再选择一张主参考与必要辅助，简短说明主辅用途并记录实际附件顺序。不默认 A1、不沿用前一人物，也不为多样性机械轮换；重复选择应有本次比较的依据。可以向模型提供全部候选，但必须先选一个主方向，说明哪些图补充什么、哪些不参与，不能平均混合互相矛盾的光向、场景、彩色与黑白。工具容量不足时，先在执行端查看全组，再仅上传选中项。

把候选选择要求写入可复制正文，同时将读取图库、比较及上传图片写入模式 README 的执行步骤。图像模型不能仅凭正文读取私有 GitHub 或本地路径；负责调用它的 Agent 必须将选中图作为真实附件传入。只有部分图可读时，说明实际候选范围；没有参考时不能声称完成图库匹配。不要通过把所有参考路径塞进正文假装完成上传。

选图理由要连接本次触发的创作规则：这张图解决什么问题，借鉴哪种关系，随主体变化需要怎样调整。检查候选库是否只覆盖一种外观而漏掉已有证据支持的关键选择；有缺口时从已核验作品中补充互补样本，无法补齐则说明。增加参考数量或全部上传不等于覆盖了决策范围。

## 人物为什么好看

人像任务在写主动版前，依据当前作品子集定义“好看”的具体含义：是什么样的人物呈现、哪些视觉关系让这种呈现成立。审美结论标为分析判断，不把某一种脸型、年龄、肤色或体型当成普遍标准。

检查实际相关的因素：构图/机位怎样呈现脸部与身体比例；眼神和嘴角是否协调；转头、肩颈、手臂和重心如何组织线条；发型怎样衬托轮廓、露出表情或提供动态；光线和肤色如何让五官清楚、皮肤显得通透；妆容、服装及局部修饰怎样配合人物。材料未覆盖的因素明确缺口，不为填满维度编造结论。

按“样片可见事实 → 对人物吸引力的作用（分析）→ 主动版具体动作 → 原片适配条件”记录，并选能显示脸部、姿态或发型差异的参考图。区分原模特个人特点与可迁移的呈现方式；不能因脸部光滑就断言作者重度磨皮，也不能把低清、压缩或过曝造成的细节缺失当成理想肤质。有妆发或修饰来源时引用，没有时只描述目标外观。

主动版可复制正文专设“人物吸引力与美化”段，明确要求人物更好看且符合该风格，写出有依据的表情、姿态、发型、面部光影、肤色及修饰动作。按原人物特点选择适用动作，不把参考人物的脸、发型或动作整套套用；以身份仍可辨认为边界，避免所有改善都被“完全保留”抵消。有原片时针对真实可改善项写，没有时用具体的条件式指令，不宣称原片存在某个缺点。

## 两种编辑模式

有用户原片时先看身份、表情动作、空间几何、光向、曝光、肤色和清晰度。没有原片时输出带适用条件的复用提示词，不声称已经完成适配。这里的模式均指图像编辑，不包含 LoRA 或模型训练。

| 边界 | 主动模式 | 微调模式 |
|---|---|---|
| 人物 | 以符合该风格的好看为目标，保持身份可辨认；按样片逻辑改善美颜、发型、表情和姿态 | 保留五官结构、体型、年龄特征、表情动作；仅局部遮瑕、修正临时痘痘或泛红，保留真实皮肤纹理 |
| 场景与构图 | 默认保留原场景地点与主要识别线索，可在同一现场重绘背景细节、调整人物位置与取景、裁切扩图；明确要求后才换地点 | 保留物体数量位置、场景、透视、主体占比、画幅与构图，不增删或重排内容 |
| 光影与色调 | 可重布光，但光源、阴影和反射需协调；用最终光色关系贴近参考 | 调整曝光、局部明暗、色相和饱和度，保持原有光向与阴影结构 |
| 冲突优先级 | 人物身份、原地点可辨与可信人体关系优先；在此范围内主动改善人物与风格，不冻结现场细节 | 原片内容、身份和几何优先，减弱不兼容的风格处理 |

上表的地点限制是保留现场模式的默认；用户已配置身份驱动的棚拍创作时，原地点不进入保留项或冲突优先级，服装、布景和拍摄呈现可重新设计。这一例外须同时写入风格介绍与可复制正文，不能只在生成时临时追加。

两版各自写完整边界，不能仅换标题或用“同上”引用另一版。主动模式要说明可改的内容及目的，不被微调版的全面保留约束抵消；微调模式不能混入换动作、换场景或重构构图。美颜和遮瑕都不等于复制参考人物的脸或漂白原肤色。

## 关键参考图也是交付物

把清晰、互补的关键作品实际保存到 `prompt-assets/reference/`，供两版共用。选择能分别说明影调、肤色、光线、人物状态或构图的少量图，避免只提供网页链接、联系表或重复样片。反例留在分析稿，解说者仿色图不得冒充摄影师原作。

从视频截取时优先找完整、无遮挡的单幅作品，必要时只裁出作品区域；保留全帧、来源 ID、时间与裁剪坐标（原始全帧像素，左上角起，x/y/width/height）。不放大伪造细节，不生成、重绘或重新调色参考图。来源归属仅由讲解者标注时明确写出，不称为已核验原作。仅有低清图或找不到干净画面时说明限制。

两种模式的 `README.md` 都用 `../reference/` 下的相对路径嵌入参考图，说明每张图用于什么，并指向 `../reference/sources.md`。保持整个 `prompt-assets/` 目录可搬移。微调版只从参考图借鉴光色和质感，主动版还可借鉴姿态、场景组织及构图逻辑；不照搬参考人物身份。

## 风格介绍页

每个风格另有一份介绍 `README.md`，与 `prompt-assets/` 同级。根据已有分析和实际提示词概括作品范围、核心摄影逻辑、人像美感目标、适合的原片与两种模式的编辑边界，链接模式目录、参考图和来源记录。提供版本信息及实际验证状态；不能只列文件清单，也不为丰富介绍新增未经研究的摄影师生平或器材结论。

介绍页负责让读者理解和选择风格，可复制的完整编辑指令仍保留在各模式的 README。导入现成资产时按其正文介绍，不用通用的“主动模式”定义覆盖该套提示词更严格的保留条件。

## 写可直接使用的提示词

每个文件包含使用方式、一个完整可复制的中文提示词块、关键参考图与简短适用说明。约定先上传自己的原片，再上传选中的参考图；按实际附件顺序说明角色。正文也写出具体风格关系，使只有原片时仍可使用，参考图角色写成条件句。

复制块本身必须包含“观看方式与内容逻辑 → 构图和视觉注意力 → 影调结构 → 分区色彩与肤色 → 质感”的相关核心判断及动作，不能只把拆解放在块外。说明相对关系和先后依赖，例如主体与背景谁更亮、极端黑白如何收敛、主色如何保留辨识度、局部校色如何纠正整体处理的副作用。模式保留项单独收拢，避免挤占真正的风格指令。

把已提炼的核心规则写成“遇到什么条件，选择或调整什么，为何有助于目标；冲突时如何取舍”的正文指令。仅看复制块也应能对新主体作出选择，不要求生成模型自行猜测摄影师思维或读取分析稿。来源与完整推导留在分析稿；未证实的意图不写成事实，仍在验证的视觉假设只能作为有限范围的设计建议。

提示词按“图片角色 → 本风格适用原片与匹配判断 → 目标视觉关系 → 本模式允许的编辑动作 → 保留项与冲突优先级”组织。将已证实的影调、分区色彩、肤色和质感动作写全，不保留未解释占位符。主动模式按该套已约定的创作边界增加美颜、动作、布景与构图建议；微调模式明确局部遮瑕及内容锁定。

用具体目标替换“电影感”“高级感”“大师感”等空词。自然语言强度描述默认足够；用户没指定模型时，不虚构 `strength`、seed、CFG、负面提示词栏或固定 Lightroom 数值。英文版、额外强度档仅在用户需要时增加。

区分作品最终规律、教程作者的实现方法和中间偏色的纠正动作。教程可能先用曲线改变冷暖、再用 HSL 或分级补偿；提示词提取最终色彩关系，不将相反的中间步骤同时固化。第三方仿色路径也不等于摄影师本人公开的处理流程。

默认交付上述两版文件及真实参考图，不替用户执行图像生成。

交付前仅阅读可复制块核对：不看分析稿也能知道该作品子集的核心逻辑；来源重点都有动作落点或明确的模式边界；去掉摄影师名字后，仍保留有区分度的构图、影调和色彩关系。不能用重复形容词或更长的禁止清单代替吸收来源。

## 创作规则的验证

在 `style-analysis.md` 中记录所用材料、规则版本、判断与限制，区分以下检查：

- **留出作品检验**：材料足够时，提炼前保留未用于归纳的作品；先固定候选规则，再看留出作品是否支持其预测的视觉关系，并记录解释失败之处。全部作品已用于提炼时只能称回看检查，不能称独立验证。
- **新情境推演**：换用不同主体或约束，检查规则能否产生有依据的方案变化，同时遵守模式边界。假设情境明确标注，不冒充真实原片观察；文字方案成立不证明生成效果成立。
- **反例检查**：用不同系列或不符合规则的作品判断是范围限制、条件遗漏还是规则错误；据此缩小、修订或删除规则，不把所有反例解释成作者“有意打破规则”。

新材料或失败案例到来时只修订受影响规则及正文落点，保留矛盾与验证限制。没有留出材料或实际结果时照实交付，不为完成检查自动扩展调研或启动图像生成。

## 有试图结果时怎样判断

仅在用户请求实际编辑或提供结果图时对比。主动模式分别检查人物是否在已定义的审美维度上更好看、是否仍可辨认、风格是否成立以及人体与空间是否可信；不能只看调色接近就算人物改善完成。微调模式额外检查表情、动作、场景、构图和五官结构未变。随后核对伪影及细节损失，只修正未生效或过度的指令。

主动版的场景检查区分换地点与现场细节重绘：把街头直接换成咖啡馆属于未授权的地点替换；原地点中的天光、花草、路人、局部背景和取景重绘，不应一概判为失败。按用户实际允许范围判断，不能把保留现实意义误解为逐像素复原。若修改了提示词、风格选择或参考附件后复测，记录实际版本与输入，不把多因素同时变化的效果单独归因于某一个因素。

没有目标模型或生成结果时，只能核验提示词的证据、模式边界与参考资产完整性，不能宣称迁移效果已通过验证，也不能保证任何图像模型都严格遵守。
