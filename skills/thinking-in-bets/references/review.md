# W3 结果复盘：把反馈变成学习

适用：失败后自责或甩锅、成功后过度自信、评估自己或他人的决定。书内基础：T01、T07–T13、T19、T35。

1. **还原决策时点。** 优先用当时的记录：目标、可用选项、已知信息、当时合理可获取但遗漏的信息、预期概率与行动理由。事后才出现的事实另列。无记录时明确是回忆重建。
2. **先评过程。** 未知结果时暂不索取结果；若已知，承认无法真正盲评，暂将它放到单独栏。检查是否考虑主要选项、核验关键假设、识别可预见风险、符合价值与限制，以及执行是否偏离计划。
3. **再看结果。** 记录实际得失、观察期限是否结束、有无关键环境变化。保留当时未发生的分支；不能因结果实现而把其事前概率改成100%。用“若结果相反，我是否仍这样评价过程？”检查结果导向。
4. **列可竞争的归因。** 分开列决策/执行、外部环境/随机因素及混合解释，写支持和反对证据。换位检查：如果是竞争者做成/做砸，我是否使用同样标准？不能凭一个结果报“能力占70%、运气占30%”。
5. **判断能学什么。** 明确遗漏信息或执行失误可直接修复；对归因不明的结果保留待验证假设。持续失败、超出原先预测范围或机制变化，要检查模型，而不是无限诉诸运气。成功也查过程缺陷，不仅复盘失败。
6. **形成一次可验证改进。** 写下保留什么、改变什么、依据是什么，以及下次什么观察能支持/否定改进。必要时转 W2 更新信念或 W7 改习惯。不要把个体的一次经历升级为普遍法则。

| 层次 | 当前评价 | 证据与不确定性 |
|---|---|---|
| 当时的决策过程 | 合理/存在具体缺陷/信息不足 | 只能用当时信息与可合理预见的风险 |
| 实际执行 | 与计划一致/偏离/未知 | 不把计划正确等同执行正确 |
| 实际结果 | 好/坏/混合/尚未结算 | 按事前目标与时限 |
| 归因与学习 | 可支持的解释、待验证的解释 | 不强求精确比例 |

**结束条件**：至少区分了过程评价与结果评价，给出有证据的改进或明确“现有证据不足以改变策略”，并说明下一次应收集什么。避免“你没错，只是运气不好”的安慰式断言，也避免“结果坏所以你不行”的人格评判。
