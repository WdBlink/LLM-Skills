# W6/W7 将未来带入现在

<a id="w6"></a>
## W6 未来侦察：情景、反向回顾与预先检查

书内基础：T24–T25、T29–T33、T35。输入：一个选项或计划、可判定的目标、期限、资源限制。

1. **固定终点。** 设定何时观察什么结果；区分成功、部分成功和失败。目标来自用户，不代其捏造指标。
2. **反向回顾。** 假设到期成功，从终点倒推必要事件、行动、依赖与先后次序。逐一问哪些由自己控制、哪些依赖别人、哪些依赖好运。若成功必须同时依靠多项渺茫条件，应调整计划或目标。
3. **预先检查。** 假设到期失败，独立列具体失败原因，尤其是难以公开表达的担忧。不是泛问“有什么风险”，而是“我们已经失败，过程中发生了什么？”失败故事是待检验假设，不能因故事生动就当事实。
4. **合并情景。** 将正反路径放回同一可能性空间。只展开会改变当前行动或预案的分支，避免穷举。给事件概率/范围及依据；真正互斥且穷尽的分支概率才要求合计100%。同一分支内部用条件概率，不把相关事件当独立事件相乘，也不让重叠风险强行加总。
5. **把情景变成行动。** 每个关键风险写“早期信号 → 预防动作 → 信号出现后的预案”；成功路径写“下一里程碑 → 所需资源/责任人 → 核验方式”。责任人未知则标待定，不擅自指派真实人员。
6. **预先承诺与记录。** 对容易情绪化地推翻的限制调用 W7。保留原始情景与预测，指定重估时点或证据，结果出来后转 W3，不抹除没发生的分支。

**最小产物**：成功依赖、主要失败机制、对应的信号与措施、当前行动。如果路径分析改变了选项排序，回 W1 更新建议；否则完成，不无限往下扩树。

**风险提醒**：多个收入机会的期望值可以相加，但共同受一个外部因素影响时不能因此认为现金流分散安全。为实际支出检查现金缺口情景；这是对书内拨款示例的执行补充。

## W7 决策中断、预先承诺与习惯替换

书内基础：T12–T16、T24–T28、T34。适用：知道该怎么做却反复违背计划，或近期得失使后续判断失衡。

1. **标记具体触发。** 从用户叙述识别追损、过度兴奋、疲劳、争吵、心跳加速，或“必须马上扳回来”“这次绝不可能失败”。包括赢了以后过度加码的倾斜。措辞只是提醒，不据此诊断心理疾病或认定用户不理性。
2. **先中断可延迟的冲动行动。** 按现实截止期设计离开现场、保存草稿、推迟发送、暂缓追加投入等措施；紧急安全行动不等待完整分析。没有延迟空间时执行最小必要行动，并明确尚未评估的部分。
3. **心理时间旅行。** 对当前选择分别想象10分钟、10个月、10年后的后果，也可回看过去类似选择。可按问题改时间尺度。将短期感受与长期总量分开，不用“十年后不重要”抹杀眼前真实损失。
4. **设计尤利西斯合约。** 在平静时明确触发条件、限制、替代行动与解除条件。可以增加坏行为阻力，也可降低好行为阻力。单说“我要更理性”不算机制；应具体到额度/时长/入口/提醒或可信伙伴，但不照搬书中600美元、6–8小时。
5. **保留合理修订路径。** 若有独立新证据或现实约束改变，在冷静状态复核后修改规则并说明依据；不能为了当前冲动即时改写，也不能让过时承诺逼人继续有害行为。
6. **替换习惯常规。** 保留“提示—奖励”，替换中间动作。例如“得到好结果 → 检查一个可能的过程缺陷 → 认可自己学到了东西”，代替“得到好结果 → 证明我英明”。可从成功案例练习，降低防御。
7. **下次检验。** 记录触发时是否执行了替代动作、哪里被绕过；按实际失败点调整最小约束。评价是否执行了好过程，不能要求下一次结果必然变好。

**承诺卡**：当〔可观察信号〕出现 → 暂停〔具体行动〕 → 执行〔替代动作〕 → 满足〔恢复/重新评估条件〕再继续；平时通过〔增加/减少阻力〕帮助执行。

**决策脏话罐**：把“我早就知道、总是、都是他的问题”等作为暂停检查的线索，改写为具体事实、证据和未知。目标是中断偏差，不能羞辱、罚款或机械禁止正确的确定性陈述；数学结论不需要装作不确定。
