# Thinking in Bets · 对赌决策工作流

Version: 0.1.0 · License: Proprietary（个人使用；原书版权归原权利人）

从用户提供的《对赌》2019年中文版直接阅读提炼：35个可操作工具，组成7条按场景组合的工作流。重点是改变决策过程，而非模仿Annie Duke说话。

- W1 选项与下注：决定做什么，何时改判。
- W2 信念审计：找依据、反证并更新判断。
- W3 结果复盘：分开评价过程、执行与结果。
- W4 求真团队：CUDOS、独立判断、异议和责任。
- W5 求真沟通：共情、真实认同、补充证据与未来行动。
- W6 未来侦察：情景规划、反向回顾、事前验尸及预案。
- W7 决策中断：心理时间旅行、预先承诺与习惯替换。

## 使用

**也由Codex自身主动触发**：用户只需给出任务目标；Codex在规划、使用工具、处理反馈或验证中发现不确定取舍、未证实假设、归因偏差或需要换路时，可自行加载相关工具，完成局部检查后继续任务，不必等待用户提醒。

支持未出现“决策”字眼的隐含需求，如排优先级、继续还是放弃、等信息还是先试、验证传闻、从竞品学习、预算预估与成功后加码，也可局部用于工程和科研任务。完整触发示例及边界见入口的“如何识别未被点名的需求”。

例如直接问：“项目失败了，是不是当初就不该做？”“两个方案的信息都不完整，周五必须选一个。”“大家都支持这个方向，怎么找出盲点？”无需点名技能。也可以显式用 `$thinking-in-bets`。

`agents/openai.yaml` 已设置 `allow_implicit_invocation: true`；描述包含自然场景，供宿主自动选择。它是允许隐式调用的配置，并非每次必触发的后台钩子。新装技能可能需要新建会话或刷新技能列表；实际触发仍由宿主与模型决定。纯事实/计算、无新问题的机械执行和明确只想倾诉时不启动完整分析；执行中发现实质不确定性仍可局部使用。

核心入口见 [SKILL.md](SKILL.md)，完整工具及原书位置见 [工具地图](references/toolkit.md)，阅读范围及实践补充见 [来源说明](references/sources.md)，可复制的表格见 [决策记录](templates/decision-record.md)。

## 安装

从仓库根目录安装到Codex：

```bash
mkdir -p ~/.codex/skills/thinking-in-bets
rsync -a skills/thinking-in-bets/ ~/.codex/skills/thinking-in-bets/
```

也可将此目录软链接至 `~/.codex/skills/thinking-in-bets`，后续修改直接生效。其他宿主需自行支持其技能发现机制，不保证识别Codex专用的调用配置。

不需要原书、API密钥、LangGraph或其他运行依赖。这里的分支选择由Agent按规则执行；在出现真实的跨轮持久状态、可恢复的多步骤自动执行需求前，无须添加编排框架。
