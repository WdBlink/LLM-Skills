# 决策记录（仅填写本次需要的部分）

## 事前：保留原版本，结果出现后不覆盖

- 决策/责任人：
- 记录时间 / 必须决策的时间 / 结果观察时间：
- 目标与偏好 / 硬约束 / 最大可承受损失：
- 选项（含相关的维持现状、延迟或小试）及机会成本：
- 已知事实及来源 / 推断 / 关键未知：
- 决定性信念、概率或范围、估计依据：
- 主要情景与后果（不能量化则明确写取舍）：
- 成功所需条件 / 失败机制：
- 最强反方理由 / 尚未解决的异议：
- 当前选择、理由、下一步：
- 哪项证据或阈值会改变选择：
- 早期信号与预案 / 预先承诺及恢复条件：

## 新证据：追加更新

- 时间 / 新证据及来源：
- 旧判断 → 新判断 / 更新理由 / 行动影响：

## 事后：分开评价

- 实际结果 / 是否达到观察期限：
- 基于当时信息的过程评价 / 实际执行：
- 可控因素 / 外部因素 / 未明归因及各自证据：
- 是否因为结果忽略了原有其他分支：
- 保留什么 / 改变什么 / 下一次如何验证：

无事前记录时注明“事后回忆重建”，不要伪装成事前预测。未填写字段只表示未知或不适用，不表示零风险。
