# 学术写作讲故事框架 (Academic Writing × Storytelling)

> 4 派综合，6 个心智模型，12 条触发器，12 步工作流 — 把"讲故事"这个看似空泛的劝诫变成可操作的认知工具。

---

## 这是什么

一个**主题型 Skill**（不是人物 Skill）。它不模拟任何具体人物，而是把"如何在学术写作中使用叙事技巧"这个领域里**4 个不同学派**的核心主张压成一个可直接套用的框架：

| 流派 | 一句话主张 | 谁会激活它 |
| --- | --- | --- |
| **Pollock 戏剧结构派** | 论文 = 五幕剧；IMRaD = 弗赖塔格金字塔的工程化版本 | 经验研究（定量 / 定性 / 理论） |
| **手艺派** | Clutter 是公敌；改稿 > 初稿；删到骨头 | 所有学术写作的"基础层" |
| **叙事转向派** | 故事可以是知识的合法形式（甚至本体），不只是修辞糖衣 | 质性 / 组织 / 文化 / 跨文化研究 |
| **科学修辞派** | 论断强度需要 epistemic warrant 刻度盘校准——hedging 不是软弱 | 所有论文（STEM 实验科学里最有价值） |

**最重要的设计选择**：本框架**不消解流派分歧**，而是把它们**显式**作为深度来源。

---

## 解决什么问题

大多数"如何写学术论文"的指南只给你单一视角（通常是"删减 + 清晰"或"叙事 + 钩子"），但实际上**4 派在不同维度是对的**：

- 想让稿子易读？ → 手艺派
- 想让引言抓住人？ → Pollock 派
- 想让方法论讨论忠实？ → 科学修辞派
- 想让质性研究有合法性？ → 叙事转向派

强行套用任何一派都会暴露短板。本 Skill 的价值在于**在合适场景下激活对应学派的工具**，并显式标注分歧（让读者知道你的选择不是唯一正解）。

## 何时使用

- 写 / 改一篇学术论文，从 abstract 到 discussion 任何阶段
- 评议别人的稿子，给出结构化反馈
- 准备基金申请 / 研究陈述 / 求职信（这些是学术写作的衍生 genre）
- 教别人写作（用 6 个模型 + 12 步工作流当教学大纲）

## 何时**不要**使用

- 你是 STEM 实验科学家、形式化理论家、算法研究者——**本框架不适用**
- 你的核心需求是**语言层**而非 genre 层——找 language editor（Nature Author Services / Enago）
- 你的需求是**政治 / 法律 / 伦理**类——本 Skill 不覆盖

## 使用示例

### 场景 1：用户贴出自己论文的一段

> 用户："我这段被审稿人吐槽太啰嗦，怎么办？"

**Skill 应答路径**（按 SKILL.md 第 7 节协议）：
1. 分类为"诊断现有草稿"
2. 激活 **Pollock 模型 2（删减=诚实）** + **五种病态标签**
3. 给出**对比改写**（原句 vs 删减后）
4. 标注主要支持学派（Pollock p.46）

### 场景 2：用户问"第一人称讲故事是不是必须的？"

**Skill 应答路径**：
1. 分类为"错误前提"
2. 引用 **模型 6（IMRaD 是修辞伪装）**——第一人称是工具不是义务
3. 区分"自传性民族志/医学叙事/Nature Comment"（第一人称合法）vs "主流实证社科/STEM"（第一人称不当）
4. 提示 ESL 作者特别注意 genre 规范

### 场景 3：用户问"我是 STEM 学者，能用这个吗？"

**Skill 应答路径**：
1. 分类为"跨学科迁移"
2. 引用**诚实边界 #3 / #4**——STEM 慎用叙事
3. **不冒进**地说"本框架对你的场景部分适用、部分不适用"
4. 给出 STEM 学者可借鉴的具体层：Fahnestock hedging / Pollock 引言钩子（不是整个戏剧结构）
