# 取证包合同

宿主完成取证后、运行 prepare 前读取。用户只需给项目范围；本 JSON 由执行技能的宿主生成，不向用户索要表格。运行目录外的 `evidence.json` 是输入，程序冻结到 `input.json`，下游不得修改。

## 顶层字段（必须恰好这些字段）

| 字段 | 类型 | 实际填写 |
| --- | --- | --- |
| `project_name` | 非空字符串 | 项目标识/名称 |
| `project_root` | 绝对路径字符串 | 本次范围，非 Git 也可；不是技能安装路径 |
| `request` | 非空字符串 | 用户原始交接请求、讨论焦点及本会话仍有效的约束；保留原话并标来源，合并必要上下文，不复制历史私有指令 |
| `generated_at` | 带时区 ISO 8601 字符串 | 实际生成时间，不使用资料里虚构/未来日期代替 |
| `version` | 非空字符串 | 已确认的分支、完整 commit、未提交/未跟踪差异；非 Git 产物版本；不知道则写明 |
| `coverage` | 非空字符串 | 项目归属、资产/历史各自截至；实际检查渠道、分页/浏览/深读/未读范围；真实总量未知及其影响；非仅“全部已读” |
| `synthetic` | 布尔值 | 仅整个样例明确为合成时 true；混合内容 false 并逐来源标注性质 |
| `sources` | 非空数组 | 下表结构；无任何可读材料也登记缺口，不能凭空写证据 |

## 每个来源（必须恰好这些字段）

| 字段 | 类型/枚举 | 要求 |
| --- | --- | --- |
| `id` | `S1`、`S2`… | 唯一，正文逐个写 `[S1]`，不写 `[S1,S2]` |
| `kind` | `file/web/session/unknown` | 本机文件/网页/只有宿主会话/无法确认实际定位 |
| `locator` | 非空字符串 | file 为本次实际读取位置的绝对路径，无行号后缀；web 为 http(s) URL；session 为真实会话 ID；unknown 为原定位及无法确认原因 |
| `location` | 非空字符串 | 行号/章节/实验 ID，或会话时间/消息 ID/分页边界；未知须说明 |
| `status` | `read/unread/unavailable/not_found` | 已读（包括明确范围的部分读取）/已发现未读/无权限或无法解析/未发现且存在性未知 |
| `scope` | 非空字符串 | 归属依据、材料种类、日期/版本、全文或已读范围、条件和局限；只有浏览也要写明 |
| `excerpt` | 字符串 | read 必须非空，其他状态必须空；摘录决定判断的已读原文与上下文，不混入猜测，不摘未读内容 |

同一文件可有多个来源条目，按不同阅读状态/区间分开；不要把同次运行多个条目当重复实验。来源清单包括相关的未读与缺失范围，无关项目只在 coverage 说明已排除及归属理由，不摘正文。

本地文件绝对路径在取证时核对存在性和读取结果；程序只验证路径形状，不假称访问检查。历史里的远程原路径保留在 scope/location，与当前导出的 locator 分开。找不到当前绝对路径用 unknown，不能把文件名拼到猜测目录。需要脱敏的路径同样用 unknown 并说明不能直接定位；普通项目路径无需替换成占位符。URL 凭据、认证参数先移除。

## 摘录应当足以支持审议

原始请求、冲突双方、失败和后续修复、改变验收的决策、有效配置等必须进入同一包。原始记录事实与宿主推断分开，推断不冒充引用。保留数字、单位、数据/配置/版本、对照条件；不得为了缩小输入而删反例。引用受版权限制，采用必要短摘录并保留充分的自写证据摘要，明确哪些是摘要。

例如结果表中的两次运行与历史里的过宽结论都要进入 sources，由 writer 判断能否推广；不能只写“后来已经解决”。历史缺失时登记不可访问渠道和缺口，writer 可以诚实写未知，不需要为了通过编造决策理由。

最终文件将包含来源定位、scope、阅读状态和 excerpt。先去掉敏感/无关内容；不能把整份原始日志复制进包后寄望 writer 自动隐藏。程序不会自动扫描账号日志，也不会证明已覆盖所有历史。

新证据或用户目标改变时保留原包与失败原因，另建输入和 run。`prepare` 只复制指定包，后续源文件变化不会刷新冻结快照。正文与评审都必须解释为该快照范围内的结果。
