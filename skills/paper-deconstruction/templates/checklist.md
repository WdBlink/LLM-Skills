# 论文精读检查清单 (40 项, 五阶法 + 配图 + 公众号专属)

按五阶法, 每阶段对照打勾。**全文配图 5-9 张**, 视觉化阶段单独检查。
**如果输出公众号 post**, 额外检查最后 5 项。

---

## 阶段 1: 结构 (2 min)

- [ ] 1. 翻目录, 画出章节地图
- [ ] 2. 标注"非典型"章节 (ViLT 的 2 页相关工作)
- [ ] 3. 找 Contributions 段 (通常在引言末尾或摘要末尾)
- [ ] 4. 数图表数 (Fig 几个, Table 几个) — 判断"方法短/实验长"

## 阶段 2: 故事 (5 min)

- [ ] 5. 读完标题 + 副标题 — 写出一句话卖点
- [ ] 6. 摘要最后一句 — 抓核心贡献
- [ ] 7. 引言第一段 — 抓痛点
- [ ] 8. 引言第二段 — 抓前人 + 局限
- [ ] 9. 引言第三段 — 抓本文方法概述
- [ ] 10. 引言末尾 — 抓贡献列表 (3 条)
- [ ] 11. 画前人时间线 (3–5 个代表工作)

## 阶段 3: 拆解 (20 min)

### 输入
- [ ] 12. 原始数据是什么?
- [ ] 13. 怎么变成模型输入 (tokenize / patch / 等)?
- [ ] 14. 序列长度多少?
- [ ] 15. 有没有模态标识?

### 模型
- [ ] 16. 抄下模型图
- [ ] 17. 主干是什么 (Transformer / CNN / GNN)?
- [ ] 18. 单 stream 还是 dual stream?
- [ ] 19. 参数量集中在哪?

### 损失
- [ ] 20. 主 loss + 辅助 loss 列出来
- [ ] 21. 每个 loss 拉什么信号?

### 训练技巧
- [ ] 22. 数据增强 (文本侧 / 图像侧)
- [ ] 23. 学习率 / batch / steps
- [ ] 24. 微调哪些层

### 数据
- [ ] 25. 预训练集几个? 多大?
- [ ] 26. 下游任务几个?
- [ ] 27. 数据集是否有获取问题?

### 实验
- [ ] 28. 主表按列读, 找"速度列"
- [ ] 29. 消融看了吗? 哪个 trick 最关键?
- [ ] 30. 可视化看了吗? 给读者什么"看得到"的成果

---

## 阶段 4: 评价 (5 min)

- [ ] 故事评分 (0/1/2)
- [ ] 方法评分 (0/1/2)
- [ ] 实验评分 (0/1/2)
- [ ] 代码评分 (0/1/2)
- [ ] 留白评分 (0/1/2)
- [ ] 写"我接下来要不要 follow"

## 阶段 5: 视觉化 (5 min)

- [ ] 31. 章节地图配了吗? (excalidraw, 放在结构段)
- [ ] 32. 前人时间线画了吗? (excalidraw, 放在故事段)
- [ ] 33. 模型架构图是论文 Fig 截图吗? (不是就换)
- [ ] 34. 数据分布图是论文饼图/条形图截图吗? (没有自画)
- [ ] 35. 主表 + 消融 + 速度曲线都从论文截了吗?

---

## 写笔记 (5 min)

- [ ] 用 `templates/output-template.md` 的 5 段格式
- [ ] 每段不超过 5 句
- [ ] 总长 1–2 页
- [ ] 视觉资产清单写在笔记开头
- [ ] 全文 5-9 张配图, 每张都有 alt + caption + 出处
- [ ] 引用论文图时, caption 注明 "图源: 论文 Fig N"
- [ ] 封面用 `social-cover-maker` 生成 (主图 + 方形)

---

## 公众号 post 专属检查 (额外 5 项, 仅在写公众号 post 时)

仅当任务是公众号 / 知乎 / 小红书 post 时, 在学术笔记基础上额外检查:

- [ ] 36. **钩子段**: 第 1 屏有"反直觉问题"展开 (2-3 段) + 1 张自画对比图
- [ ] 37. **配图比例**: 自画 ≥ 截图 (典型 4:3 或 4:4)
- [ ] 38. **架构图**: 用论文 Fig 截图, 不要自己重画 (保真度优先)
- [ ] 39. **趋势段**: 必有 X-free 演进时间线 (自画), 把本文放进 lineage
- [ ] 40. **收尾段**: 必有"N 个 follow 方向"路线图 (自画) + 回扣钩子句

附加规则:
- [ ] 文件命名: `<paper-slug>-wechat.md`, 配图目录 `assets/<paper-slug>-wechat/`
- [ ] 自画图编号: `01_<descriptor>.png` → `04_<descriptor>.png` (叙事顺序)
- [ ] 截图命名: `figXX_<descriptor>.png` (XX = 论文 Fig 编号)
- [ ] 6 段叙事骨架: 钩子 / 痛点 / 方案 / 实验 / 趋势 / 收尾 (用 `---` 分隔)
- [ ] 收尾必有金句: "<某某>的本质, 永远是<某某>" 之类的升华句
