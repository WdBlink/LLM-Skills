# 公众号精读 Post 模板 (微信 / 知乎 / 公众号通用)

> 区别于学术笔记 (`output-template.md`): 学术笔记是给"未来的自己 + 同行"看的工程文档, 公众号 post 是给"路过的读者"看的故事 + 钩子。
> 同一篇论文, 两种模式, 走五阶法走两遍 — 学术笔记定结构, 公众号 post 重叙事。

---

## 关键差异 (vs 学术笔记)

| 维度 | 学术笔记 | 公众号 post |
|---|---|---|
| 长度 | 1-2 页 / 5 段 | 3-5 屏 / 6 段 |
| 钩子 | 无 | **第 1 屏必须有反直觉钩子** |
| 配图数 | 5-9 张 | 6-8 张 |
| 配图风格 | 截图为主, 自画为辅 | **自画 ≥ 截图 (4:3 或 4:4)** |
| 表格 | 多, 全表罗列 | 少, 只留主表 1 张 |
| 收尾 | follow 计划 | **趋势判断 + 5 个可挖坑 (自画路线图)** |
| 文件命名 | `<slug>-notes.md` | `<slug>-wechat.md` |
| 配图目录 | `assets/<slug>/` | `assets/<slug>-wechat/` |

---

## 6 段叙事骨架

```
1. 钩子 (反直觉小问题 + hook 对比图)         ← 第 1 屏必有图
2. 痛点 (慢三件套 / 老方法 N 个不爽)           ← 可无图, 文字密度足够
3. 核心方案 (拆 3-4 块 + 论文 Fig 截图)        ← 2-3 张论文截图
4. 实验 (3-4 张主表, 一句话总结)               ← 表格, 无图
5. 趋势 / 思想溯源 / X-free 演进                ← 1 张自画时间线
6. 收尾 (回扣钩子 + N 个 follow 方向)          ← 1 张自画路线图
```

每段过渡用 `---` 分隔, 每段开头 1 行加粗主题句。

## 钩子段写作模板 (硬骨头)

钩子是第 1 屏决定读者留不留下的关键。3 种模板:

### 模板 A: 反直觉问题

> 我们让 X 做 Y。这事听起来很小。但你去看现在最强的 A / B / C, 它们是怎么做这件事的? <展开旧做法的"傻"> 这就是 <X> 的根本痛点。

适用: 当老做法存在但被默认接受时。 

### 模板 B: 数字对比

> X 跑 5 BPS, Y 跑 12.7 BPS。2.5× 加速不是工程优化, 是范式变化。今天把这个范式讲透。

适用: 当卖点是 "数字碾压" 时。

### 模板 C: 概念回望

> N 年前, <老论文> 砍掉了 <X>; 今天 <新论文> 砍掉了 <Y>。**X-free 套路从 <旧领域> 转移到了 <新领域>**, 这是过去 N 年最重要的范式迁移之一。

适用: 当新工作站在 lineage 上时。

## 收尾回扣模板 (升华)

收尾的"写在最后" 段, 3 步走:

1. **回扣钩子**: 重复开头的反直觉问题
2. **抽象本质**: 把现象抽到 "X 的本质是 Y" 的高度
3. **总结一击**: 一句金句, 例 "创新的本质, 永远是质疑一个被默认的设计"

不要写 follow 计划在这段 — follow 已经在趋势段写过。这段是**思想升华**, 不是工程总结。
