# 接到一篇新论文: 第一步填的 brief

接到一篇要精读的论文, 先花 5 分钟填完这个 brief, 决定精读深度。

```markdown
## Brief: 《<论文标题>》

- **链接 / PDF**: <arxiv / openreview / 会议页>
- **作者 / 单位**: <第一作者, 通讯作者>
- **会议 / 年份**: <NeurIPS 2024 等>
- **代码**: <GitHub 链接或 "无">
- **被引数 (粗略)**: <大致数量级>

## 一句话卖点 (从标题 + 摘要末句推断)
<20 字内>

## 我为什么读这篇
- [ ] 组会汇报
- [ ] 找 follow 方向
- [ ] 写 related work
- [ ] 了解新领域
- [ ] 写综述

## 阅读深度
- [ ] 速览 (10 min, 摘要+引言+图 1+主表+结论)
- [ ] 标准精读 (45 min, 四阶法)
- [ ] 深度精读 (3 hour, 复现关键实验)

## 时间预算
- [ ] 速览
- [ ] 标准精读 (4 阶)
- [ ] 深度精读 + 笔记

## 输出
- [ ] 1 段组会 slide
- [ ] 5 段精读笔记 (用 output-template)
- [ ] related work 段
- [ ] 复现计划
```

---

## 速览的 10 分钟模板 (如果选速览)

```markdown
# 速览: 《<标题>》

- **卖点**: <一句话>
- **方法一句话**: <什么主干 + 什么数据>
- **主表亮点**: <top 1 在哪个任务>
- **速度 / 精度取舍**: <取舍方向>
- **值得 follow 吗**: <是 / 否 / 观望, 一句话>
```

10 分钟够用, 后续按需升级到标准精读或深度精读。
