# chapter-digests.md — ViLT 视频章节切分

源视频时长 63:25, 切成 7 个大段, 每段一个"教学主题"。

---

## 段 1: 开场 + 论文意义 (0:00–1:18)

**主题**: 为什么 ViLT 是里程碑

**要点**:
- ViLT 是 ICML 2021 oral, 推动了过去一年多模态学习
- 核心贡献: 把 region feature 从多模态框架中**移除**
- "天下苦目标检测久矣" (讲师原话)
- 类比: DETR 简化目标检测 → ViLT 简化多模态

**对应四阶法**: 阶段 2 (故事) 的痛点铺垫。

---

## 段 2: Fig 1 速度对比 (1:19–4:30)

**主题**: 卖点的视觉化

**要点**:
- Fig 1 把 ViLT 跟 region feature / grid feature / patch projection 三种方法的速度并列
- 视觉抽取: 885ms → 0.4ms (**1000× 加速**)
- 但精度: region feature 仍然最好 (76.1 vs 75.8, 微小差距)
- 讲师: "卖点最大化体现, 读者跟着节奏走"

**对应四阶法**: 阶段 2 (故事) 的卖点可视化 + 阶段 3 (拆解) 的实验部分。

---

## 段 3: 标题 + 摘要 (4:31–10:38)

**主题**: 怎么读标题和摘要

**要点**:
- 标题 "ViLT" = Vision-Language Transformer
- 副标题 "Without Convolution or Region Supervision" — X-free 类标题
- 摘要结构: 背景 → 痛点 → 方法 → 结果 → 开源承诺
- "几乎所有 VLP 都用 ITM + MLM 这两个 loss"
- 讲师: "摘要写得很直白, 没有花哨"

**对应四阶法**: 阶段 1 (结构) + 阶段 2 (故事) 的卖点提取。

---

## 段 4: 引言 + 故事 (10:39–27:56)

**主题**: 怎么讲故事

**要点**:
- 引言三段式: 背景 → 痛点 → 本文
- 三个贡献: 极简 / 性能不掉 / 新的数据增强
- 讲师强调的"X-free"标题套路在这里系统化
- "你可以把它想象成是句子那边的某一个单词" — 把 region 类比成 token
- 端到端 vs 预训练检测器 — 讲师把"上线推理"作为隐含痛点

**对应四阶法**: 阶段 2 (故事) 主体, 阶段 3 (拆解) 的输入和数据部分。

## 段 5: 相关工作 + Fig 2 (27:57–38:17)

**主题**: 写综述 = 找痛点 + 找题目

**要点**:
- 相关工作 2 页, 综述味浓
- Fig 2: 把 VLP 按 VE / TE / MI 三个维度分类
- A 类 (VSE): VE >> TE, MI 太浅
- B 类 (CLIP): VE = TE, MI 浅, 适合 retrieval
- C 类 (UNITER/Oscar): VE >> TE, MI 深, 性能好
- D 类 (ViLT): VE = TE, MI 深 — 理想组合
- 讲师: "Fig 2 被引用很多, 综述图的标准范式"
- 讲师建议: "初入领域者不妨写综述, 中不中稿不重要"

**对应四阶法**: 阶段 1 (结构) 的"非典型章节"识别 + 阶段 3 (拆解) 的方法背景。

## 段 6: 主体方法 (38:18–49:41)

**主题**: 六块拆解 (输入/模型/损失/训练技巧)

**要点**:
- Fig 3: 单个 Transformer encoder, 文本 + 图像 concat 输入
- ITM loss + WPA loss (optimal transport) + MLM loss
- WWM (whole word masking) — 整词 mask, 强制看图
- RandAugment 改版 — 禁用 color jitter + cutout, 防破坏配对
- 讲师: "trick 是 follow 论文的导火索"

**对应四阶法**: 阶段 3 (拆解) 主体, 2/3 时间花在这里。

---

## 段 7: 实验 + 消融 + 结论 (49:42–1:02:48)

**主题**: 怎么看实验 + 怎么找 follow 方向

**要点**:
- 4M 数据集: COCO + VG + GCC + SBU
- 主表: VQA / NLVR2 (分类) + Retrieval (zero-shot + fine-tune)
- 消融: 25K/50K/100K 训练步数 + WWM / RandAugment / 组合
- 结论: proof of concept, 不追求 SOTA
- 三个 future work: scalability / 图像重建 / 数据增强
- 讲师: "一年都被填了 — ALBEF / BEiT / MAE / mixgen"
- 终极建议: "没题目时, 读 future work"

**对应四阶法**: 阶段 3 (拆解) 的实验 + 阶段 4 (评价)。

## 视频作为方法论载体的几个特点

1. **时长充裕 (63 min)**: 让讲师能深入到每个细节 (如 WPA loss 用 optimal transport, 1 分钟单独讲)
2. **配合论文图**: 73 个讲图锚点, 几乎每个概念都有图支撑
3. **元层面评论**: 不只讲论文, 还在讲"怎么读论文" — 适合做教学材料
4. **诚实承认局限**: 讲师多次说"这个方法不复杂"、"性能不是 SOTA", 不夸大
5. **指向未来工作**: 不仅是 paper review, 还在给学生"找题"指南
