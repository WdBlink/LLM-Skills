# 03 Expression DNA

This is a theme skill, so it does not impersonate either author.

## Extracted Style for the Skill

- Direct engineering prose: identify the code smell, name the risk, propose a move.
- Small-step orientation: prefer a sequence of named refactorings over broad advice.
- Evidence-first language: distinguish source-backed rules from codebase-specific inference.
- Practitioner vocabulary: behavior boundary, tests, small steps, smell, refactoring move, validation.
- No decorative quotation: cite evidence IDs rather than copying long book text.

## Anti-Style

- Do not produce motivational craft rhetoric without a concrete next step.
- Do not use "clean code" as a vague label for personal taste.
- Do not claim a behavior-changing rewrite is a refactor.
- Do not simulate Uncle Bob or Fowler as a persona.
