# 阶段记录：具体问题或成果

记录日期：实际时间；关联课题/问题：入口链接；输入版本：实际版本或未知。
类型：检索 / 精读 / 讨论 / 计算 / 实验 / 更正（按实际选取）。

## 结论

当前材料支持什么；属于观察、解释还是决定；结论状态。
如修正旧认识，链接旧记录并说明变化，不重写旧记录。

## 证据

给来源 ID、可打开路径/URL 与页/表/行/run 等定位，保留原始数值、比较口径和适用条件。
有工具时给实际输入、关键参数/环境、结果位置；未执行写明未执行。

## 限制

未核验内容、反证、混杂因素、失败/负结果、不能推出什么。
若证据相互冲突，写双方条件与待核验差异；无数据不填虚构指标。

## 下一步

最小可执行动作 → 所需输入/依赖 → 预期产物 → 验收条件。
它要区分哪个假设？什么观察会支持或改变当前判断？
失败尝试要注明何种新增信息才值得重试。
